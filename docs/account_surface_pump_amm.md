# `pump` and `pump_amm` account surface, read from the deployed bytes

Anchor generates one accounts struct per instruction. The generated `try_accounts` frame pulls one `AccountInfo` per declared field off a slice iterator and raises one Anchor error per violated constraint. This page records that surface for the two largest deployed programs, handler by handler: the dispatcher entry, the `AccountInfo` record, the fetch sites, and every constraint raise site with its code, its name, the account it names, and the check that guards it. Generated by `tools/account_surface.py`; the raw records are in `maps/pump_account_surface.json` and `maps/pump_amm_account_surface.json`.

## Dispatcher entries

Each handler is attributed by the bytes that dispatch it: the discriminator constant is `sha256("global:" + name)[:8]` carried as the `lddw` immediate, the following `jeq` branches to a stub, and the stub reaches the handler with a call or a jump.

## The `AccountInfo` record

The shared fetch helper advances an iterator by **48** bytes and raises **3005** when it runs out, which fixes the record stride and its field offsets:

| field | offset | read by |
|---|---:|---|
| `key` | 0 | key compares (2001 has_one, 2012 address, seeds) |
| `lamports` | 8 | lamport reads |
| `data` | 16 | account data (discriminator + Borsh body) |
| `owner` | 24 | owner compares (2004 / 3007) |
| `rent_epoch` | 32 | rent-exempt constraint (2005) |
| `is_signer` | 40 | signer constraint (2002) / AccountNotSigner (3010) |
| `is_writable` | 41 | mut constraint (2000) / AccountNotMutable (3006) |
| `executable` | 42 | executable constraint (2007) |

The iterator is a two word cursor `{ptr@0, remaining@8}`: a fetch checks `remaining`, decrements it, takes `ptr` and stores `ptr + 48` back. Fetch helpers measured per program:

| program | fetch helper frames | first frames |
|---|---:|---|
| `pump` | 15 | `0x24`, `0x3a`, `0x51`, `0x595`, `0x24f4`, `0x25f0` |
| `pump_amm` | 14 | `0x24`, `0x3a`, `0x51`, `0x46e`, `0x1f4b`, `0x204c` |
