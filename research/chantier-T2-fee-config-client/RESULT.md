# chantier-T2: legacy fee config through the pump_fees client account, 1 window matched

Refs T2 (SPECS §5, fee-config deserializer forms) and #19. Stacks on `chantier-T2-client-decl-lines` (#81).

## What the deployed program does

- The legacy and v2 trade account structs read `fee_config` as `Account<'info, pump_fees::accounts::FeeConfig>`, the account type generated by `declare_program!(pump_fees)`.
- Window `0x1159d8` is that generated `FeeConfig::try_deserialize_unchecked` (1176 bytes), which Borsh-decodes the full fee config account.
- `LegacyFeeConfig` and `LegacyFeesProgram` are re-exports of the generated `pump_fees` account and program types, not hand-written wrappers.
